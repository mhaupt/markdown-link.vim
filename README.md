# markdown-link.vim

A plugin for [MacVIM](https://macvim.org). When editing Markdown files, and some
text is selected, and the clipboard contains a URL, the selected text will be
replaced with a Markdown link to that URL when you hit Cmd-V to paste. Cmd-V
behaves as usual in other circumstances.

To install, just place the `markdown-link.vim` file in your MacVIM plugins
folder, e.g., `~/.vim/plugin`.
